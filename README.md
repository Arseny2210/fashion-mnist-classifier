## 📌 Описание проекта
В данной лабораторной работе реализована сверточная нейронная сеть (CNN) на базе TensorFlow/Keras для классификации предметов одежды из набора данных **Fashion-MNIST** (10 классов, 70 000 изображений). Обученная модель внедрена в два варианта интерактивного веб-сервиса:
1. **Streamlit веб-сервис (`app.py`)** — полноценный графический интерфейс с возможностью загрузки файлов, тестированием готовых образцов из датасета, визуализацией конвейера предобработки (28×28 Grayscale) и графиком распределения вероятностей.
2. **FastAPI REST API (`api.py`)** — высокопроизводительный серверный API с автодокументацией Swagger UI (`/docs`) и встроенным HTML/JS интерфейсом для моментального тестирования в браузере.

---

## 🏗️ Архитектура сверточной сети (CNN)
Модель построена на базе блочной модульной архитектуры:
- **Входной слой:** `Input(shape=(28, 28, 1))`
- **Сверточный блок 1:**
  - `Conv2D(32, (3, 3), padding='same', activation='relu')`
  - `BatchNormalization()`
  - `MaxPooling2D((2, 2))`
  - `Dropout(0.25)`
- **Сверточный блок 2:**
  - `Conv2D(64, (3, 3), padding='same', activation='relu')`
  - `BatchNormalization()`
  - `MaxPooling2D((2, 2))`
  - `Dropout(0.25)`
- **Полносвязный классификатор:**
  - `Flatten()`
  - `Dense(128, activation='relu')`
  - `BatchNormalization()`
  - `Dropout(0.35)`
  - `Dense(10, activation='softmax')`

## 🚀 Инструкция по запуску

### 1. Самый простой веб-сервис на FastAPI (с HTML-шаблоном)
```bash
python3 main.py
```
или
```bash
uvicorn main:app --reload --port 8000
```
Откройте в браузере: **`http://127.0.0.1:8000`**

### 2. Запуск интерактивного UI на Streamlit
```bash
streamlit run app.py
```
Откройте в браузере: **`http://localhost:8501`**

### 3. Запуск расширенного REST API с Swagger UI (`api.py`)
```bash
uvicorn api:app --reload --port 8000
```
- Документация Swagger: `http://localhost:8000/docs`
